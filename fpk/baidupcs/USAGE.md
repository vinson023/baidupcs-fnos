# 使用说明（BaiduPCS for fnOS）

## 下载
文件保存到安装时填写的下载目录（默认 `/vol1/1000/downloads` 或应用共享目录），
可在飞牛「文件管理」中直接查看、改名、移动。

## 上传（重要）
本应用运行在飞牛上，**读取的是飞牛存储里的文件**，不是直接读取你电脑上的文件。
浏览器没有直传通道，上传流程是「先在飞牛上放文件，再到应用里选文件」：

1. 用飞牛「文件管理」上传、SMB/网络磁盘、或直接拖进共享目录，把文件放到存储空间；
2. 打开应用 →「网盘管理」→ 右上角「上传」；
3. 在内置文件浏览器里选中第 1 步放好的文件或文件夹（可多选）；
4. 选好网盘目标目录与冲突策略，确定后任务进入「上传管理」页。

> 提示：下载目录本身就是很好的中转区——网盘下到 NAS、再从 NAS 传回网盘都可以直接选它。

## 首次登录
打开应用后扫码（百度网盘 App）或粘贴浏览器 Cookie 完成登录；多账号可在账号菜单里添加。

## 改设置
- 下载目录、运行用户：飞牛「应用中心 → 百度网盘 → 设置」（修改后自动重启）。
- 并发线程、分片大小、Web 访问密码、代理等：应用界面右上角「设置」。

## 端口与外网访问
Web 端口固定 **18888**，桌面图标指向 `<协议>://飞牛地址:18888`。改端口会导致图标打不开。

应用内置 **HTTP/HTTPS 自适应入口**：同一个 18888 端口，收到 TLS 握手就用飞牛托管的证书
（按域名 SNI 选择）终止加密，收到纯 HTTP 就直接转发。因此：

- 内网 `http://IP:5666` 打开桌面 → iframe 走 http，正常；
- 外网用域名走 `https://域名:5667` 打开桌面 → iframe 走 https，同样正常，且证书与飞牛主站一致。

**外网仍需要在路由器把 TCP 18888 转发到这台飞牛**（与 5666/5667 同理）。若只映射了主站端口，
图标会停在空白页。

## 卸载
在飞牛「应用中心」卸载时会让你选择**是否保留配置文件**：

| 选项 | 行为 |
|---|---|
| 保留配置文件（推荐） | 账号登录状态、任务记录、数据库、日志与设置全部保留，重新安装后可直接继续使用 |
| 不保留，全部删除 | 删除本应用在系统中的全部配置与数据：`@appconf`、`@appdata`、`@apphome`、`@apptemp`、`@appmeta`、`@appcenter` 下属于本应用的目录，以及应用专用的系统账号 |

两种情况都**不会删除你已下载的文件**。共享目录（文件管理器里的 `baidupcs/downloads`）只有在其中已无任何文件时才会一并移除。

清理过程会写日志到 `/tmp/baidupcs-uninstall.log`；若仍有残留，卸载界面会给出提示。
